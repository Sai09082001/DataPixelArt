# DataPixelArt

Static No.Pix-format content snapshot for Pixel Art.

- 12443 stable catalog records; 12180 public drawing payloads.
- 263 locked payloads are not published. Locked metadata and existing public previews remain locked.
- Pixel grids use lossless gzip. Validate dataSha256 against the decompressed PCAT bytes.
- PNG previews and artwork images are copied byte-for-byte.
- No application source, Firebase configuration, credentials, user-created pictures, or progress data is included.
- integrity.json records checksums and the exported file inventory.

Use a pinned commit, not the moving main branch:

`https://cdn.jsdelivr.net/gh/Sai09082001/DataPixelArt@COMMIT/nopix/...`

The catalog is at nopix/catalog.json. Content rights remain with their respective rights holders; this repository does not grant additional redistribution rights.
